## ¿Qué es un Ticket?

Un ticket es un registro temporal de productos que un cliente quiere comprar. Es como una "lista de compras" que se guarda para procesar después.

**Cuándo usar un ticket**:
- Cuando un cliente está viendo productos pero aún no decide
- Cuando quieres guardar una selección para procesar después
- Cuando hay una fila de clientes y quieres agilizar el proceso
- Cuando el cliente necesita tiempo para decidir

---

## ¿Qué es una Cotización?

Una cotización es como un ticket pero con precios estimados que se envía al cliente para que decida si quiere comprar. Es útil para clientes que quieren saber el costo antes de decidir.

**Cuándo usar una cotización**:
- Cuando un cliente quiere un presupuesto antes de comprar
- Cuando envías precios a un cliente por email/WhatsApp
- Cuando el cliente necesita aprobación de su jefe o supervisor
- Cuando el cliente quiere comparar precios

## Cómo Acceder a Tickets y Cotizaciones

1. Inicia sesión como administrador o empleado
2. Haz clic en "Admin Local" en el menú superior
3. Selecciona "Tickets y Cotizaciones" del menú desplegable
4. Verás la página de gestión de tickets y cotizaciones

---

## Cómo Crear un Nuevo Ticket

### Pasos

1. Haz clic en "+ Nuevo Ticket"
2. Se abrirá un formulario para crear el ticket

**Paso 1: Buscar o Crear Cliente**
- Si el cliente ya existe:
  - Escribe el nombre, email o teléfono
  - Selecciona el cliente de la lista
- Si el cliente no existe:
  - Haz clic en "Crear Nuevo Cliente"
  - Ingresa nombre, email, teléfono
  - Haz clic en "Guardar"

**Paso 2: Agregar Productos**
- Usa el buscador para encontrar productos
- Escribe el nombre o SKU del producto
- Selecciona el producto de la lista
- Haz clic en "Agregar"
- Modifica la cantidad si es necesario
- Repite para cada producto

**Paso 3: Revisar el Carrito**
- Verifica que todos los productos sean correctos
- Verifica las cantidades
- El sistema calculará el total automáticamente

**Paso 4: Agregar Notas**
- Agrega instrucciones especiales si el cliente las tiene
- Ejemplo: "Cliente quiere que le avisen cuando llegue el producto"

**Paso 5: Guardar**
- Haz clic en "Guardar Ticket"
- El ticket quedará guardado con un número (ej: TKT-2024-00123)
- El estado será "Pendiente"

## Cómo Crear una Nueva Cotización

### Pasos

1. Haz clic en "+ Nueva Cotización"
2. Se abrirá un formulario similar al de ticket

**Paso 1: Buscar o Crear Cliente**
- Igual que en ticket
- Es importante tener el email para enviar la cotización

**Paso 2: Agregar Productos**
- Igual que en ticket
- Agrega todos los productos que el cliente quiere cotizar

**Paso 3: Revisar el Carrito**
- Verifica productos y cantidades
- El sistema mostrará el total estimado
- Este es el precio que el cliente verá

**Paso 4: Agregar Notas**
- Agrega condiciones si es necesario
- Ejemplo: "Precios válidos por 30 días"

**Paso 5: Guardar**
- Haz clic en "Guardar como Cotización"
- La cotización quedará guardada con un número (ej: COT-2024-00156)
- El estado será "Pendiente"

## Cómo Ver Tickets y Cotizaciones

### Qué Verás

Lista de todos los tickets y cotizaciones. Para cada uno verás:
- **Número**: TKT- o COT- seguido del número
- **Nombre del cliente**: Quién hizo la solicitud
- **Fecha**: Cuándo se creó
- **Tipo**: Ticket o Cotización
- **Monto total**: Cantidad estimada
- **Estado**: Pendiente, Enviado, Convertido, etc.

### Filtros Disponibles

- **Tipo**: Tickets, Cotizaciones, Todos
- **Estado**: Pendiente, Enviado, Convertido, Cancelado
- **Fecha**: Rango de fechas
- **Cliente**: Cliente específico

## Cómo Convertir un Ticket en Venta

### Cuándo Convertir

Cuando el cliente decide comprar los productos del ticket.

### Pasos

1. Busca el ticket en la lista
2. Haz clic en "Convertir a Venta"
3. El sistema te llevará al Punto de Venta
4. El carrito ya estará lleno con los productos del ticket
5. Completa el proceso de venta normalmente:
   - Selecciona método de pago
   - Procesa el pago
   - Imprime el ticket

**Resultado**:
- El ticket cambia a estado "Convertido"
- Se crea una venta en el sistema
- El inventario se actualiza
- El cliente recibe su compra

## Cómo Enviar una Cotización por WhatsApp

### Pasos

1. Busca la cotización en la lista
2. Haz clic en "Enviar WhatsApp"
3. El sistema abrirá WhatsApp con un mensaje prellenado

**Qué incluye el mensaje**:
- Número de cotización
- Lista de productos
- Cantidad de cada producto
- Precio unitario
- Precio total
- Total general
- Vigencia de la cotización

4. Revisa el mensaje
5. Haz clic en "Enviar"
6. El cliente recibirá la cotización por WhatsApp

**Ventajas**:
- El cliente recibe la cotización instantáneamente
- Puede responder directamente
- Es más personal que email

## Cómo Imprimir Tickets y Cotizaciones

### Cómo Imprimir

1. Busca el ticket o cotización en la lista
2. Haz clic en "Imprimir"
3. Se abrirá una ventana con el documento listo para imprimir

### Qué Incluye el Documento

- Número de ticket/cotización
- Fecha y hora
- Datos del cliente
- Lista completa de productos
- Cantidades y precios
- Subtotal, IVA, total
- Notas si las hay
- Vigencia (si es cotización)

### Opciones de Impresión

- Imprimir en impresora conectada
- Guardar como PDF
- Enviar por email

## Cómo Eliminar un Ticket o Cotización

### Cuándo Eliminar

- Cuando el cliente ya no está interesado
- Cuando hubo un error al crearlo
- Cuando es una duplicación

### Pasos

1. Busca el ticket o cotización en la lista
2. Haz clic en "Eliminar"
3. Confirma la eliminación
4. El ticket/cotización desaparecerá de la lista

**Consideración**:
- Una vez eliminado, no se puede recuperar
- Si necesitas conservar el registro, no lo elimines

## Solución de Problemas

### Problema: No puedo encontrar un ticket

**Solución**:
- Verifica que estés usando los filtros correctos
- Intenta buscar por número de ticket
- Intenta buscar por nombre de cliente
- Verifica que el ticket no haya sido eliminado

### Problema: El cliente no recibió la cotización por WhatsApp

**Solución**:
- Verifica que el número de teléfono sea correcto
- Verifica que el cliente tenga WhatsApp
- Reenvía la cotización manualmente
- Envía por email como alternativa

### Problema: El precio cambió después de crear la cotización

**Solución**:
- Crea una nueva cotización con el precio actual
- Notifica al cliente del cambio
- Explica la razón del cambio
- Ofrece mantener el precio anterior por un tiempo limitado

## Buenas Prácticas

### Usar Tickets para Agilizar

- Crea tickets cuando hay fila
- Guarda selecciones de clientes indecisos
- Convierte tickets en ventas rápidamente

### Enviar Cotizaciones Rápidamente

- Envía cotizaciones el mismo día que se solicitan
- Usa WhatsApp para respuestas más rápidas
- Incluye vigencia clara en la cotización

### Mantener Registros

- No elimines tickets/cotizaciones antiguos
- Útiles para referencia futura
- Útiles para análisis de ventas

### Seguir con Clientes

- Contacta a clientes con cotizaciones pendientes
- Pregunta si decidieron
- Ofrece ayuda si tienen dudas
