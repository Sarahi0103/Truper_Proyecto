## ¿Qué es la Validación de Tickets?

Es el proceso de verificar que un ticket de compra es válido y no ha sido usado anteriormente. Se usa para promociones, devoluciones, canjes de garantía y programas de lealtad.

**Cuándo usar validación**:
- Cuando un cliente quiere canjear una promoción
- Cuando un cliente presenta un ticket para devolución
- Cuando un cliente quiere usar garantía
- Cuando un cliente quiere canjear puntos de lealtad

---

## Cómo Acceder a Validación de Tickets

1. Inicia sesión como administrador o empleado
2. Haz clic en "Admin Local" en el menú superior
3. Selecciona "Validación de Tickets" del menú desplegable
4. Verás la página de validación de tickets

---

## Cómo Validar un Ticket

### Por Número de Ticket

**Pasos**:
1. En la sección de búsqueda, escribe el número del ticket
   - Ejemplo: TKT-2024-00123
2. Haz clic en "Validar"
3. El sistema buscará el ticket en la base de datos
4. Verás el resultado de la validación

### Por Código QR

**Qué es un código QR**:
Un código de barras cuadrado que contiene información del ticket. Se puede escanear con la cámara del dispositivo.

**Pasos**:
1. Haz clic en "Escanear QR"
2. La cámara del dispositivo se activará
3. Apunta la cámara al código QR del ticket
4. El sistema leerá el código automáticamente
5. El ticket se validará automáticamente

**Si no tienes cámara**:
- Pide al cliente que muestre el número de ticket
- Valida por número de ticket como se explicó arriba

---

## Qué Resultados Puedes Obtener

### Ticket Válido

**Qué verás**:
- Mensaje verde: "✅ Ticket Válido"
- Información del ticket:
  - Número de ticket
  - Fecha de emisión
  - Cliente
  - Productos
  - Total
  - Estado (No canjeado)

**Qué puedes hacer**:
- Ver detalles completos
- Canjear promoción (si aplica)
- Procesar devolución (si aplica)
- Ver historial de uso

### Ticket Inválido

**Qué verás**:
- Mensaje rojo: "❌ Ticket Inválido"

**Posibles razones**:
- El ticket no existe en el sistema
- El ticket ya fue canjeado anteriormente
- El ticket expiró (pasó la fecha de vigencia)
- El ticket fue cancelado
- El código QR es incorrecto

**Qué hacer**:
- Verifica el número de ticket con el cliente
- Pide al cliente que muestre el ticket original
- Verifica la fecha de emisión
- Contacta al administrador si hay dudas

## Cómo Canjear una Promoción con Ticket

### Cuándo Canjear

Cuando el cliente presenta un ticket que tiene una promoción asociada:
- Descuento especial
- Producto gratis
- Puntos de lealtad
- Oferta exclusiva

### Pasos

1. Valida el ticket como se explicó arriba
2. Si el ticket es válido y tiene una promoción:
   - Verás la promoción disponible
   - Verás los detalles de la promoción

3. Haz clic en "Canjear Promoción"

4. **Seleccionar la promoción**:
   - Si hay múltiples promociones, selecciona la deseada
   - Verifica los términos y condiciones

5. **Confirmar el canje**:
   - Haz clic en "Confirmar Canje"
   - El sistema aplicará el descuento automáticamente
   - El ticket se marcará como canjeado

6. **Resultado**:
   - La promoción se aplica a la compra actual
   - El cliente recibe el beneficio
   - El ticket ya no se puede usar nuevamente

## Cómo Ver Detalles de un Ticket

### Qué Información Verás

**Información básica**:
- Número de ticket
- Fecha y hora de emisión
- Nombre del cliente
- Email del cliente (si está registrado)

**Información de productos**:
- Lista completa de productos
- Cantidad de cada producto
- Precio unitario
- Precio total por producto
- SKU de cada producto

**Información financiera**:
- Subtotal de productos
- Descuentos aplicados
- IVA
- Total pagado

**Información de estado**:
- Estado actual (Activo, Canjeado, Cancelado)
- Fecha de canje (si fue canjeado)
- Número de veces canjeado

**Información de promociones**:
- Promociones asociadas
- Estado de cada promoción
- Fecha de canje de promociones

### Cómo Ver Detalles

1. Después de validar el ticket
2. Haz clic en "Ver Detalles"
3. Verás toda la información del ticket
4. Puedes imprimir o guardar como PDF

## Solución de Problemas

### Problema: El código QR no se escanea

**Solución**:
- Verifica que el código QR esté claro y legible
- Asegúrate de que haya buena iluminación
- Mantén la cámara estable
- Intenta validar por número de ticket

### Problema: El ticket no aparece en el sistema

**Solución**:
- Verifica que el número de ticket sea correcto
- Verifica que el ticket haya sido emitido en tu tienda
- Contacta al administrador si el ticket es de otra tienda
- Verifica que no haya error en el número

### Problema: El ticket dice que ya fue canjeado pero el cliente dice que no

**Solución**:
- Verifica la fecha y hora de canje
- Pide al cliente detalles de cuándo supuestamente lo canjeó
- Verifica si hubo canje no autorizado
- Contacta al administrador para investigación

### Problema: La promoción no se aplica

**Solución**:
- Verifica que la promoción esté vigente
- Verifica que el ticket sea elegible para la promoción
- Verifica que no haya condiciones especiales
- Contacta al administrador si persiste

## Buenas Prácticas

### Validar Siempre

- Valida todos los tickets antes de procesar
- No asumas que un ticket es válido
- Esto previene fraudes

### Verificar Identidad

- Pide identificación al cliente
- Verifica que el cliente sea el titular del ticket
- No aceptes tickets de terceros sin autorización

### Mantener Registro

- Registra todas las validaciones
- Anota motivos de rechazo
- Útil para auditorías y análisis

### Comunicarse Claramente

- Explica al cliente por qué un ticket es inválido
- Ofrece ayuda para resolver problemas
- Sé profesional y cortés
