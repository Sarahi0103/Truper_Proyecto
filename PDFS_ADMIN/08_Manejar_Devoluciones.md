## ¿Qué es el Sistema de Devoluciones (RMA)?

RMA significa "Return Merchandise Authorization" (Autorización de Devolución de Mercancía). Es el sistema formal para gestionar solicitudes de devolución de productos de manera organizada.

**Funciones principales**:
- Recibir solicitudes de devolución de clientes
- Aprobar o rechazar solicitudes
- Generar etiquetas de envío para devoluciones
- Procesar reembolsos
- Llevar registro de todas las devoluciones

---

## Cómo Acceder a Devoluciones

1. Inicia sesión como administrador o empleado
2. Haz clic en "Admin Tienda" en el menú superior
3. Selecciona "Devoluciones RMA" del menú desplegable
4. Verás la página de gestión de devoluciones

## Cómo Ver Solicitudes de Devolución

### Filtros Disponibles

**Por Estado**:
- Pendiente: Esperando aprobación
- Aprobado: Aprobado, esperando producto
- Rechazado: Solicitud rechazada
- Completado: Reembolso procesado

**Por Fecha**:
- Rango de fechas específico
- Hoy, Esta semana, Este mes

**Por Tipo**:
- Producto: Devolución de producto
- Reembolso: Solo reembolso
- Reemplazo: Cambio por otro producto

### Información de Cada Solicitud

En la lista verás para cada solicitud:
- **Número de solicitud RMA**: Ej: RMA-2024-00123
- **Número de pedido original**: Ej: ORD-2024-00156
- **Nombre del cliente**: Quién solicita la devolución
- **Monto a reembolsar**: Cuánto dinero se debe devolver
- **Motivo de devolución**: Por qué el cliente quiere devolver
- **Estado actual**: En qué estado está la solicitud

## Cómo Aprobar una Devolución

### Cuándo Aprobar

**Motivos válidos para aprobar**:
- El producto está defectuoso
- El producto no es lo que el cliente ordenó
- El producto llegó dañado
- El cliente tiene derecho a devolución por política (dentro de los 30 días)

### Pasos

1. En la lista de solicitudes, haz clic en "Ver Detalles"
2. Revisa la información del cliente:
   - Nombre y datos de contacto
   - Número de pedido original
   - Fecha de compra

3. Revisa la información del producto:
   - Nombre del producto
   - Cantidad
   - Precio

4. Revisa el motivo de devolución:
   - Motivo seleccionado por el cliente
   - Descripción detallada del problema

5. Revisa la evidencia (si la hay):
   - Fotos del producto
   - Videos mostrando el problema
   - Documentos adicionales

6. Haz clic en "Aprobar"

7. **Seleccionar el tipo de reembolso**:
   - **Reembolso al método de pago original**: El dinero vuelve a la misma tarjeta/cuenta
   - **Tienda de crédito**: El cliente tiene crédito para futuras compras
   - **Reemplazo del producto**: Se envía un producto nuevo

8. **Agregar notas** (opcional):
   - Instrucciones especiales para el cliente
   - Detalles sobre el proceso de devolución

9. Haz clic en "Confirmar Aprobación"

10. **Resultado**:
    - El cliente recibirá un email con instrucciones
    - Se generará una etiqueta de envío (si aplica)
    - La solicitud cambiará a estado "Aprobado"

## Cómo Rechazar una Devolución

### Cuándo Rechazar

**Motivos válidos para rechazar**:
- El producto no tiene defecto
- El cliente pasó el periodo de devolución (más de 30 días)
- El producto fue usado indebidamente
- Falta evidencia del problema
- El producto no es elegible para devolución (productos de higiene, etc.)

### Pasos

1. En la lista de solicitudes, haz clic en "Ver Detalles"
2. Revisa toda la información de la solicitud
3. Haz clic en "Rechazar"

4. **Seleccionar o escribir el motivo del rechazo**:
   - Producto sin defecto
   - Periodo de devolución excedido
   - Producto usado indebidamente
   - Falta evidencia
   - Producto no elegible
   - Otro (especificar)

5. **Agregar notas explicativas**:
   - Explica claramente por qué se rechaza
   - Proporciona detalles si es necesario
   - Sé específico y profesional

6. Haz clic en "Confirmar Rechazo"

7. **Resultado**:
    - El cliente recibirá un email con la explicación
    - La solicitud cambiará a estado "Rechazado"
    - El cliente puede apelar si lo desea

## Cómo Procesar el Reembolso

### Cuándo Procesar

Después de recibir el producto devuelto y verificar que:
- El producto está en las condiciones descritas
- No hay daño adicional
- Todos los componentes están incluidos

### Pasos

1. En la lista de solicitudes aprobadas, busca la devolución
2. Haz clic en "Procesar Reembolso"

3. **Verificar el producto recibido**:
   - Compara con la descripción original
   - Verifica que no haya daño adicional
   - Confirma que todos los componentes estén presentes

4. **El sistema procesará el reembolso automáticamente**:
   - **Si fue tarjeta**: El reembolso se hace a la misma tarjeta
   - **Si fue efectivo**: Se genera nota de crédito
   - **Si fue SPEI/transferencia**: Se hace transferencia de vuelta

5. **Tiempo de reembolso**:
   - Tarjeta: 3-5 días hábiles
   - Efectivo: Inmediato (nota de crédito)
   - SPEI/transferencia: 1-2 días hábiles

6. **Resultado**:
    - La solicitud cambia a estado "Completado"
    - El cliente recibe confirmación del reembolso
    - El inventario se actualiza (si el producto se puede revender)

## Cómo Generar Etiqueta de Devolución

### Qué es la Etiqueta de Devolución

Es una etiqueta de envío prepagada que el cliente usa para enviar el producto de vuelta a la tienda. El cliente no paga el envío.

### Cuándo Generar

Después de aprobar una devolución y antes de que el cliente envíe el producto.

### Pasos

1. En una solicitud aprobada, haz clic en "Generar Etiqueta"
2. El sistema creará una etiqueta de envío automáticamente
3. La etiqueta incluye:
   - Dirección de retorno de la tienda
   - Código de barras para seguimiento
   - Número de guía

4. **Opciones para el cliente**:
   - Imprimir la etiqueta
   - Enviar la etiquiqueta por email
   - Descargar como PDF

5. **Instrucciones para el cliente**:
   - Imprimir la etiqueta
   - Pegarla en el paquete
   - Llevarlo al correo o transportista
   - El envío está prepagado

## Políticas de Devolución

### Periodo de Devolución

- **30 días**: Periodo estándar para devoluciones
- **15 días**: Para productos en promoción
- **7 días**: Para productos de liquidación

### Productos No Elegibles

- Productos de higiene personal
- Productos de seguridad (usados)
- Productos personalizados
- Software y productos digitales

### Condiciones del Producto

- El producto debe estar en su empaque original
- Todos los componentes deben estar incluidos
- No debe haber daños adicionales
- Debe tener evidencia de compra

### Reembolsos

- Reembolso completo si el producto está defectuoso
- Reembolso parcial si hay uso normal
- No reembolso si el producto fue dañado por el cliente

## Buenas Prácticas

### Responder Rápidamente

- Revisa las solicitudes de devolución diariamente
- Responde dentro de 24 horas
- Esto mejora la satisfacción del cliente

### Ser Claro y Profesional

- Explica claramente las decisiones
- Usa lenguaje profesional
- Proporciona detalles cuando rechaces

### Documentar Todo

- Mantén registros de todas las devoluciones
- Guarda evidencia de problemas
- Útil para análisis de calidad de productos

### Comunicarse con Clientes

- Notifica a los clientes de cada paso
- Proporciona instrucciones claras
- Ofrece ayuda cuando sea necesario

## Solución de Problemas

### Problema: El cliente no recibió la etiqueta

**Solución**:
- Verifica que el email del cliente sea correcto
- Reenvía la etiqueta manualmente
- Permite que el cliente la imprime en tienda

### Problema: El producto llegó dañado

**Solución**:
- Toma fotos del daño
- Contacta al transportista
- Procesa reclamación si es necesario
- Aproba la devolución si es culpa del transportista

### Problema: El reembolso no se procesó

**Solución**:
- Verifica que la información de pago sea correcta
- Contacta al banco o procesador de pagos
- Procesa manualmente si hay error técnico
